# To-Do List

Простой веб-сайт списка задач, созданный на React + TypeScript + Vite.

## Что реализовано

- добавление новых задач
- отметка выполненных задач
- удаление задач
- сохранение списка после перезагрузки страницы через localStorage
- аккуратный и адаптивный интерфейс

## Технологии

- React
- TypeScript
- Vite
- CSS

## Запуск проекта

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Описание

Проект представляет собой мини-приложение для управления задачами. Данные сохраняются в браузере, поэтому список остается после обновления страницы.

Используемый стек: React + TypeScript + Vite.
